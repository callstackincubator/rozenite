# Standalone App

:::warning Experimental
The standalone app is opt-in and may change in future releases.
:::

The standalone Rozenite app opens the same plugin panels you see in React Native DevTools, but in their own browser window instead of embedded in a DevTools tab.

## Why use it

React Native DevTools tears down and reloads its Rozenite panel whenever the app's JS VM reloads (for example, on a Fast Refresh that touches native state, or after a crash and restart). The standalone app connects to the device over its own CDP WebSocket, so plugin panels keep their state across a JS-VM reload instead of being reset.

## Launching it

Run `rozenite open` in your project:

```bash
npx rozenite open
```

This lists the devices currently connected to Metro and opens the standalone app in your default browser for the one you pick.

### Options

- `--host <host>` — Metro host to connect to (default `127.0.0.1`).
- `--port <port>` — Metro port to connect to (default `8081`).
- `--deviceId <id>` — Open a specific device directly, skipping the picker prompt.

```bash
npx rozenite open --deviceId <id>
npx rozenite open --host 192.168.1.10 --port 8081
```

`rozenite open` requires an interactive terminal — it opens a browser window and (without `--deviceId`) prompts you to pick a device, so it refuses to run in CI or a piped/non-TTY shell.

## Limitations

- **Metro must be running.** `rozenite open` discovers devices through Metro's own device list, and the app itself is served by Metro. If Metro stops after you've opened the app, it shows a "dev server unreachable" state until Metro is back.
- **It competes for the single debugger slot.** The standalone app connects directly to the device the same way React Native DevTools and `rozenite agent` do. Only one of these can be attached to a given device at a time — the last one to connect wins, disconnecting whichever was attached before it.
- **It's opt-in.** Nothing changes about your existing React Native DevTools setup; the standalone app is an additional way to open the same panels, started explicitly with `rozenite open`.
