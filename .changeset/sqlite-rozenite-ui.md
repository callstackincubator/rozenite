'@rozenite/sqlite-plugin': minor
---

The SQLite panel now uses the shared Rozenite panel design, with a light theme alongside the
dark one. The database explorer, data browser, structure view, SQL editor and the row, drop and
confirmation dialogs all match the other Rozenite panels, and the editor follows the theme. The
panel is lighter too: it no longer bundles HeroUI. Row edit and delete actions now sit next to
the row number so they stay in reach on wide tables, and copying results or an error, exporting
and saving a query confirm with a toast. Column resizing in the result tables is gone.
