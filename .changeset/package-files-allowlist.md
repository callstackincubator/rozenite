The published packages no longer include development fixtures, tests and build
configuration (such as `rozenite.config.ts`, `__tests__` and `tsconfig.json`),
which makes installs smaller; `@rozenite/expo-atlas-plugin` alone drops from
about 6 MB to 90 KB. Plugins generated by `rozenite init` get the same treatment: they publish only
their built output, without `rozenite.config.ts`, sources, tests or build
configuration.
